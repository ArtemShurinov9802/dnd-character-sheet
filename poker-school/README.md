# За столом — тренер по кэш-покеру

Самостоятельная учебная школа на русском: безлимитный техасский холдем, кэш 6-max, без анте. Работает как статический сайт без API-ключей, платежей и реальных денежных ставок.

## Возможности

- 14 теоретических блоков: шесть базовых и восемь продвинутых.
- 59 ситуационных задач с объяснениями, тематическими подборками и повтором ошибок.
- Четыре пошаговые учебные раздачи (15 решений) с явно обозначенным продолжением по учебной линии.
- Полный симулятор на шесть игроков: префлоп, флоп, тёрн, ривер, вскрытие, фолды, ставки, рейзы, олл-ины и побочные банки.
- Стек 40 / 100 / 200 BB; смешанный, тайтовый, коллирующий или агрессивный стол; случайные или целенаправленно выбранные типы стартовых рук.
- Режим с контекстными подсказками и самостоятельный режим с разбором после руки.
- Необязательный учебный рейк: 5%, максимум 3 BB, без рейка при отсутствии флопа. Рейк округляется вниз до сотой BB и последовательно вычитается из разыгрываемых банков до общего предела.
- Журнал последних 50 раздач, заметки по решениям, статистика тем и экспорт в JSON.
- Интерактивные позиции, карта 169 классов стартовых рук, калькуляторы ставок и цены колла.

## Запуск

Откройте `index.html` в браузере либо запустите статический HTTP-сервер. Из корня репозитория, если установлен Python:

```sh
python -m http.server 8080 --directory poker-school
```

Затем откройте `http://localhost:8080`. Для самой школы не нужны npm, сборка или серверная база. Шрифт загружается через Google Fonts; без сети используется системный шрифт.

Адреса разделов используют hash-навигацию: `#/table`, `#/drills`, `#/advanced`, `#/scenarios`, `#/history`, `#/progress`. Сайт можно размещать в подпапке обычного статического хостинга.

## Учебная модель и границы

Стратегия ботов основана на эвристиках и их собственных картах, открытом борде и публичных действиях. Она не является GTO-солвером. Подсказки тренера не получают карты соперников и будущий борд. В свободной игре они дают контекст и вопросы для разбора, а не выдуманную оценку оптимальности в EV.

Пошаговые учебные раздачи идут по заранее заданной линии после разбора ответа; это явно обозначено в интерфейсе. В свободном симуляторе действия соперников зависят от текущей ситуации и действий игрока.

Карты перемешиваются воспроизводимым генератором для повторов учебных рук. Генератор не предназначен для азартных игр на деньги. При выборе типа руки стартовые карты намеренно отбираются под упражнение. Перед каждой новой рукой стеки восстанавливаются до выбранной глубины. Если все соперники сбросили, рука заканчивается без обязательного открытия пяти общих карт.

Учебная карта открытия консервативна и действует только после фолдов предыдущих игроков. Диапазоны зависят от стеков, рейка и соперников. Калькулятор цены колла сам не оценивает эквити.

Счётчики задач и результаты против ботов показывают учебную практику, а не подтверждённое преимущество над реальным полем. Курс не гарантирует прибыль и не охватывает каждую возможную покерную ситуацию.

## Сохранение

Ключ `za-stolom.training.v2` в `localStorage`: ответы, попытки, выбранные настройки, изученные продвинутые блоки, результаты учебных линий и последние 50 завершённых раздач. Данные остаются в браузере на конкретном адресе сайта; облачной синхронизации нет. Незавершённая свободная раздача после перезагрузки не восстанавливается. Экспорт журнала доступен на странице прогресса.

## Код и проверки

- `engine.js` — правила торговли, оценка лучших пяти карт, расчёт банков, боты и контекст тренера.
- `app.js`, `course.js` — базовый курс, карта рук, калькуляторы, навигация.
- `advanced.js`, `drills.js` — дополнительные материалы и учебные линии.
- `trainer.js` — симулятор, журнал, прогресс и взаимодействия.
- `*.css` — оформление и адаптивные стили.

Для разработки и воспроизводимых тестов: Node.js из диапазона `engines` в `package.json` и pnpm 11.19.0. Из папки `poker-school`:

```sh
pnpm install --frozen-lockfile
pnpm test
```

Проверки включают комбинации, кикеры и делёж, порядок торговли, минимальные рейзы, запрет повторного рейза после короткого олл-ина и его открытие накопленными повышениями, побочные банки, невостребованные ставки, нечётную фишку, рейк, неизменность состояния при неверном действии и отсутствие скрытых карт во входных данных тренера. Стресс-проверка разыгрывает 800 случайных и 200 бот-рук с сохранением общего баланса фишек. Проверки интерфейса охватывают маршруты, завершение руки, журнал, сохранение заметок и ответов, повторы и пошаговую учебную линию.

Данная папка независима от приложения D&D. Исходники подготовлены в отдельной ветке; настройки публикации и корневой сайт D&D не менялись.
