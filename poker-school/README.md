# За столом — школа кэш-покера

Самостоятельный учебный сайт на русском языке. База курса: безлимитный техасский холдем, кэш 6-max, эффективный стек 100 BB, без анте.

## Что внутри

- Семь разделов: позиции, правила и комбинации, стартовые руки, сайзинги, математика колла, постфлоп и практика.
- Интерактивный стол с вращением кнопки и тренировкой определения позиции.
- Карта 169 классов стартовых рук для UTG, HJ, CO, BTN и SB.
- Калькуляторы размера ставки и порога эквити для колла.
- 24 учебные задачи с объяснениями, выбором темы и повтором ошибок.
- Адаптивный интерфейс и ссылки на отдельные разделы через hash-навигацию.

## Запуск

Откройте `index.html` в современном браузере. Для локального HTTP-сервера, если установлен Python:

```sh
python -m http.server 8080 --directory poker-school
```

Команда запускается из корня репозитория. Затем откройте `http://localhost:8080`.
Сборка и установка зависимостей не нужны. Основные функции не требуют сервера, регистрации или API-ключей. Шрифт Manrope загружается через Google Fonts; без сети используется системный шрифт.

## Файлы

- `index.html` — оболочка приложения.
- `app.js` — учебные материалы, диапазоны, задачи и расчёты.
- `course.js` — обзор курса, маршруты и визуальные элементы уроков.
- `style.css`, `course.css` — оформление и адаптивные стили.

## Проверка

```sh
node --check poker-school/app.js
node --check poker-school/course.js
```

При подготовке проверены навигация, смена позиций, карта рук, положительное и отрицательное ожидание колла, неверный ввод, ответы на задачи и повтор ошибок; интерфейс просмотрен на ширинах 390 и 1440 пикселей.

## Ограничения учебной модели

Диапазоны и стратегические ответы — консервативные учебные ориентиры, а не решения GTO-солвера. Карта открытия применяется только после фолдов всех предыдущих игроков. Калькулятор колла предполагает одного соперника, отсутствие рейка, последующих ставок и побочных банков; эквити вводит пользователь.

Результаты упражнений хранятся в памяти страницы и сбрасываются при перезагрузке. Денежные ставки, платежи и реальные игры отсутствуют.

Эта папка независима от приложения D&D. Добавление исходников не изменяет его сборку и не настраивает автоматическую публикацию покерной школы.
